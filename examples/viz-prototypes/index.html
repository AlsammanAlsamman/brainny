brAInny — visualization prototypes

Standalone mockups for a third dashboard tab, on top of the existing Graph and Stats views — each answering "what's growing" and "what's proven useful" a different way. All use the same fabricated example dataset as examples/demo/ (never real captured ideas). real data uses the dataset's actual fields as-is; adapted reshapes something (e.g. capture order instead of wall-clock time) because this one-session demo dataset doesn't span enough real time/sessions to show the pattern otherwise — noted on each page; custom-built is a bespoke visualization, not one of the 10 generic chart-type options.

8. Flow diagram: domain → kind → origin

Hand-built flow ribbons (no d3-sankey dependency, same vendored-D3-only discipline as the real dashboard). Shows which domains lean toward which kinds, and who tends to originate them.

Adapted for this demo: the natural version of this idea is session → domain → kind, but this dataset has only one session, which would make that first column pointless. Domain → kind → origin uses three dimensions that actually vary in this data; on real, multi-session data, session → domain → kind becomes worth building instead (or alongside).

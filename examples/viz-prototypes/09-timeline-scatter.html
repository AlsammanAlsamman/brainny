9. Timeline scatter

One dot per idea: x = when it was captured, y = domain, size = evidence weight, color = kind. A denser, more analytical sibling of the calendar heatmap — good for spotting exactly which domains were active in the same stretch of work.

Adapted for this demo: x-axis uses capture order (the sequence ideas were added in), not wall-clock time — this one-session dataset's real timestamps span minutes, not the days/weeks this view is meant to show. On real, longer-lived data this uses actual last_touched timestamps directly.

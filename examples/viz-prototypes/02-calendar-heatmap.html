2. Calendar heatmap

GitHub-contributions-style grid — one cell per day, shaded by how many ideas were captured/touched that day. Directly shows real activity rhythm: bursts, dry spells, streaks.

Adapted for this demo: this fabricated dataset was generated in one real session, so every idea's actual last_touched is the same day — a real calendar heatmap of it would be one dark cell and 89 empty ones. To show what the pattern looks like with real accumulated usage, each idea's date below is deterministically jittered across the last 90 days (seeded from its id, not random per reload). On real data this uses the genuine last_touched timestamp, no jitter.

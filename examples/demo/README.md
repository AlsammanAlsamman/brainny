# brainny example dashboard

**Entirely fabricated data** — generated to show what brainny's dashboard
looks like with a real, varied set of ideas: every `kind` (technique,
precaution, solution, insight, seed, skill), every `origin`
(human/AI/collaborative), a few attachments (code/table/plot "signs"),
inline `snippet`s, and three AI-proposed `Opportunities`. None of this is
the maintainer's real captured data — see `../../assets/badge-example.svg`
and the maintainer's own dogfooded `brainny-out/` for that distinction.

Regenerated by hand whenever the dashboard changes meaningfully enough to
be worth re-showing (not on every commit) — see `OPERATIONS.md`'s step on
this for the exact commands used to build it.

## View it

- **Live, no download:** [htmlpreview.github.io](https://htmlpreview.github.io/?https://raw.githubusercontent.com/AlsammanAlsamman/brainny/master/examples/demo/graph.html)
  (GitHub doesn't render `.html` files directly; this wraps the raw file so it
  displays in your browser — the same one-file, zero-network dashboard as
  always underneath).
- **Locally:** clone the repo and open `examples/demo/graph.html` directly.
